Organizar janelas

Linux BR Desktop 1.1.1 · Mudanças nos guias

Use os botões na barra de título para minimizar, maximizar ou fechar. Arraste uma janela até uma borda para encaixá-la. Pressione Alt + Tab para alternar entre janelas abertas.
