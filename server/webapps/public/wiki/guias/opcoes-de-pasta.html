Configurar a exibição das pastas

Linux BR Desktop 1.1.1 · Mudanças nos guias

Escolha ícones ou detalhes na aba Visualização. Abra Opções de Pasta → Modo de Exibição para configurar separadamente itens ocultos e arquivos protegidos do sistema. Ctrl + H alterna os itens ocultos na pasta atual.
