ESCOLHAS COM CLAREZA

Mais caminhos para seus aplicativos.

O Linux BR reúne programas nativos, aplicativos web com base no Chromium e ferramentas como Wine e Steam/Proton. A compatibilidade com software Windows varia por título, versão e hardware. Drivers, antitrapaça e alguns recursos podem exigir Windows.
